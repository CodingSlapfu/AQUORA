# AQUORA v0.7.26 testing acceptance

Device source commit 3d78cb88f38c68024be7e46da5fccc2c0da7cc36. Native identity FM-1_73000726. See SHA256SUMS for the native and browser artifacts.

- Vocal reliability: reproduced rejection at the native deadline voice limit with bass, live notes and sequenced leads occupying the available slots. A sampled vocal can now replace a sequenced lead when optional slots are unavailable. Live notes and bass stay protected. The VOCALS Play Along panel exposes starts and denied allocations. Direct-vocal PCM passed all 24 sequential mode transitions with concurrent FX edits and all 1,200 control-change windows. The owner-reported hardware silence still requires physical confirmation.
- Navigation: SELECT turns through all eight main pages. ALGORITHM browses each page's tabs. Hold EDIT while turning ALGORITHM for contextual adjustments such as MIX channel or bus and SETUP diagnostics. SEL cycles instrument tracks on SOUND and keeps its existing contextual actions on the other pages. PRESETS continues to select intentions. In fullscreen, SELECT exits and ALGORITHM leaves the performance controls in place.
- Tempo: Standard 62–89, Cinematic 48–76, Neoclassical 64–104, Experimental Ambient 79–116 and IDM 108–159 BPM. Selection favors the center of each mode's range. An A→B→A visit regenerates the song and avoids repeating A's last automatic BPM within that mode during the session. Manual tempo locks and bank tempo recall pass their host checks.
- Vocal delivery and animation: preserved the existing intention-aware director, recorded vocabulary, motif development and manual FX. Favorites now restore the remembered vocal hook and production settings. The portrait adds a beat-locked listening pose, glances and lights between sung phrases. Mouth movement stays tied to direct-vocal activity. The candidate does not add new words, change the vocal composition grammar, or demonstrate a subjective improvement in hooks or articulation.
- Favorites: 16 numbered slots with intention, mode and BPM summaries. Open SETUP → USER SONGS, choose a slot with K1, press SEL to load while stopped, or SAVE to store. For an occupied slot, turn K3 to arm overwrite, then press SAVE. Existing slots retain their original object IDs and sector pairs. New slots use 12 independent A/B pairs in 0xA0000–0xB7FFF, within the platform's application data area, below MIDI/panel/BLE sectors and outside the application image and update staging. AQUORA embeds its samples in the firmware. The common CRC, final-header commit and readback transaction remains in use. V11 stores the existing song state plus singer settings and hook data. The host saved and recalled all 16 across simulated reboot with exact snapshot CRCs. Legacy V1–V10 reads passed. The production storage code passed 16-slot NOR simulation, overwrites and interrupted payload/header writes.
- Rollback: earlier firmware and installers remain available. A slot rewritten as V11 requires v0.7.26 or later for recall. v0.7.25 and earlier do not read V11. Export/back up existing favorites before flashing if you plan to roll back. The added sectors were checked against the AQUORA map. User data from unrelated custom firmware in the same application data region has not been examined.
- Builds: two native packages matched byte-for-byte. WASM boot, audio and framebuffer smoke passed. Installer protocol simulations covered stable, previous testing and same-version upgrades plus package corruption and wrong return identity. See the accompanying logs.
