# AQUORA

**M-VAVE FM-1 · Generative Sound Sanctuary**

AQUORA is the new, independent FM-1 sound-healing-inspired generative music firmware project. Features include generative instruments, Solfeggio frequency tones, gentle drums, stereo binaural beats, living soundscapes, and a four-page UI.

**Development status:** Not yet a verified flashable release. Do not flash developmental sources or use unverified installers.

## Project entry point

Start with [WORK_MODE_START_HERE.md](WORK_MODE_START_HERE.md), then [ACTIVE_SCOPE.md](ACTIVE_SCOPE.md), [CHECKPOINT.md](CHECKPOINT.md), and [FM1_HARDWARE_OPTIMIZATION_STANDARD.md](FM1_HARDWARE_OPTIMIZATION_STANDARD.md).

The initial source migration is a **snapshot** from the pre-existing multi-project repository, `CodingSlapfu/FM-1-Firmware-Projects`. The original repository remains intact as a backup. Future AQUORA changes should use this repository, after checking for any active Work session and synchronizing any newer commits from the old checkout.

**Never mark the firmware released without native build, acceptance tests, matching artifacts, and verified hosted installer.** Physical device testing is performed by the owner.
