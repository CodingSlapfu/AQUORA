# AQUORA 0.6.0 software candidate

Updater identity is FM-1_73000600. The matching package includes native firmware, the emulator, browser installer and manual. Keep the 0.5.0 package for rollback.

AQUORA adds a combined musical-track and source-bus mixer, Play Along strength and groove, evolving intention arrangements, Resonance, experimental AIR, Quick Find and per-track brightness, attack and release edits. The patch editor shows a cached oscillator and envelope preview. New edits are neutral by default and persist in arrangement banks.

The native and forced single-core builds use the pinned AC79 inputs. The boot and EQ reference mismatch warnings also occur in the previous candidate and 0.5.0 used the same pinned inputs as 0.4.0. The staged updater checks verify package handling in software.

Physical AIR response, delivered LCD FPS, DMA stability, key feel, flash/rollback and power-cycle persistence remain unverified. Check them on an FM-1 before relying on the candidate for a live session.
