# AQUORA 0.6.2

Original ambient generative firmware for the M-VAVE FM-1.
Updater identity: **FM-1_73000602**. Eight musical roles including drums.

This version reconciles primary e281f618 and recovery c056115 while preserving
both histories. It retains prior fixes and adds the independently generated
OFL-licensed AQUORA Sans font, three optical UI sizes, black/white surfaces,
four original panel skins, a larger eight-track console and focused strip,
direct editable SOUND sections, and an 83-parameter Quick Find registry.

Binaural steady-state tuning/fades are cached without collapsing the two ear
oscillators or routing them through shared FX. Both independent test suites
are retained; the actual three-hour kernel test measured a 0.499907 Hz difference
at the 1000 Hz / 0.5 Hz corner. No physical speedup is claimed from host timings.

Nature/patch/kit libraries retain their IDs, with intention/style selection,
locks, procedural stereo wildlife, appended FM timbres, stronger kick/hand
transients, ongoing musical evolution and returning motif memory. Polar Bloom
has thirteen intention geometries and bounded actual-audio/onset reactivity.
Hidden graphs/geometry/history stop; musical generation keeps running.

AIR reports live versus stored calibration, packet rate and raw/filtered signal.
Reverb Bloom, Echo Throw and combined mappings have bounded depth and manual
fallback. FX/depth persist; temporary modulation and radio reset at boot.
AIR remains an experimental receive-only radio-strength controller. No validated
XY or advanced gesture recognition is claimed.

The release is created only after isolated native and bit-identical native-repro,
forced single-core, WASM, sanitized DSP, host UI, migration and staged updater
gates. The acceptance archive carries source commit, build logs, maps,
software timing, listening comparisons, screenshots and checksums. Source and
packaged browser installer are also provided separately and in the download ZIP.
Prior releases remain available. The separate single-core firmware disables the
optional geometry worker; the normal firmware retains fallback.

Browser installer: https://parallax8-studio.jminie66.chatgpt.site/install/
The matching installer is deployed and verified separately after this GitHub
backup succeeds. Until that verification, the site may still serve 0.6.1.

features and artistic cymatics-inspired visuals, without medical efficacy claims.
